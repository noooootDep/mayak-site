Методы неразрушающего контроля ЛНК «МАЯК»

Специалисты лаборатории аттестованы на II и III квалификационные уровни в соответствии с правилами аттестации персонала в области неразрушающего контроля:

01 // УЗК

Ультразвуковой контроль

Обнаружение внутренних дефектов (пор, трещин, шлаковых включений, непроваров) в сварных соединениях и поковках по ГОСТ Р 55724-2013.

Прибор: А1212 MASTER
02 // УЗТ

Ультразвуковая толщинометрия

Высокоточное измерение толщины стенок сосудов, резервуаров, труб и обечаек с точностью до 0.01 мм для выявления коррозионного износа.

Прибор: ТУЗ-2, А1207
03 // РК

Радиографический контроль

Рентгеновский и гамма-контроль сварных стыков с документированием на рентгенографическую пленку или цифровую пластину по ГОСТ 7512-82.

Аппарат: АРИНА-7, СБК-160
04 // ВИК

Визуально-измерительный контроль

Базовый и обязательный метод контроля геометрических параметров швов, дефектов формы, подрезов и зазоров по РД 03-606-03.

Набор: ВИК «Эксперт»
05 // МПК

Магнитопорошковый контроль

Индикация микротрещин, волосовин и расслоений на поверхности ферромагнитных металлов по ГОСТ Р 56512-2015 с высокой чувствительностью.

Дефектоскоп: МД-М
06 // ПВК

Капиллярный контроль (ПВК)

Контроль проникающими веществами для выявления сквозных и поверхностных микродефектов в нержавеющих и немагнитных сплавах.

Наборы: Sherwin, Magnaflux
07 // Твердометрия

Динамическая твердометрия

Определение твердости металла шва и околошовной зоны по шкалам Бринелля (HB), Роквелла (HRC) и Виккерса (HV) без разрушения детали.

Твердомер: ТЭМП-4
08 // Тепловизор

Тепловизионный аудит

Диагностика тепловых потерь, футеровки печей, состояния контактных соединений электроустановок и термических мостов ограждающих конструкций.

Тепловизор: Testo 875
